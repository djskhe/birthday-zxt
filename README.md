# 曾祥婷 · 十八岁生日快乐

一张单文件、可离线打开的生日贺卡网页。

## 打开方式

- 线上：GitHub Pages（部署后填这里）
- 本地：双击 `index.html`，或 `python3 -m http.server` 后访问

## 这一版里有什么

- **配色**：浅蓝 / 淡粉 / 星空紫渐变，没有黑底白字
- **背景**：樱花花瓣 + 满天星闪光 + 光斑 + 星点，双层 canvas
- **主角**：蛋小黑（SVG 手绘，会眨眼、挥手、蹦跳）
- **首屏**：「点我拆礼物」按钮，或直接戳礼物盒
- **开盒**：盖子飞起 → 蛋小黑跳出来 → 祝福卡淡入
- **蛋糕**：三层粉白蛋糕，插满 **18 根蜡烛**，可点「吹蜡烛 · 许个愿」
- **吹蜡烛**：火焰逐支熄灭、冒烟，飘出撒花，出现收尾祝福
- **音乐**：Web Audio 合成的舒缓背景乐（八音盒 + 弦垫 + 混响），点击后淡入，可开关
- **文案**：四句祝福，落款「补上的生日 · 蛋小黑代送」

## 技术说明

- 零依赖：没有 CDN、没有外链图片、没有音频文件，全部内联
- 支持 `prefers-reduced-motion`、安全区（刘海屏）、深色模式外的浅色主题
- 移动端优先，同时兼容桌面
- 音效在用户手势后才启动，符合浏览器自动播放策略

## 部署

```bash
GITHUB_TOKEN=xxx ./deploy.sh            # 默认 owner 由 git 推断，可在脚本里改
```

`deploy.sh` 会：创建仓库 → 推送 `main` → 开启 Pages（根目录）→ 打印网址。
