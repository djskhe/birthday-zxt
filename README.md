# 给曾祥婷的十八岁生日贺卡

**线上地址：https://djskhe.github.io/birthday-zxt/**

一封信 → 一张祝福 → 一个星空蛋糕。单文件、可离线、无外链。

## 三个界面

1. **信封**：粉白信封 + 火漆印，轻触火漆（或点「点我拆礼物」）→ 火漆裂开、封盖翻开、蛋小黑蹦出来
2. **信纸**：祝福卡逐行淡入，蛋小黑趴在卡片上沿；「去看蛋糕 · 许个愿 ↓」
3. **蛋糕**：星空紫场景，三层星空蛋糕（照 B 站视频的蛋糕做的：三层深蓝星系纹理、白缎带、白瓷盘），插着 18 根蜡烛；点「吹蜡烛 · 许个愿」→ 火焰逐支熄灭、冒烟、撒花、愿望浮出

## 技术

- 单文件 `index.html`，无 CDN / 无图片 / 无音频文件，全部内联 SVG + CSS + JS
- 背景：樱花花瓣 + 满天星闪光，双层 canvas（花瓣在内容后，撒花在内容前）
- 音乐：Web Audio 实时合成的舒缓背景乐（八音盒 + 弦垫 + 混响），点击火漆后淡入，可开关
- 适配移动端（`100dvh` + 安全区）、支持 `prefers-reduced-motion`
- 音效遵循浏览器自动播放策略，只在用户手势后启动

## 预览 / 部署
